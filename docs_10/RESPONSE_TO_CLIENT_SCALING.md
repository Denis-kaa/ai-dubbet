# Ответ заказчику: Масштабирование GapirAI.uz на 2000–3000 пользователей

---

## Текущая архитектура

У клиента **5 AWS серверов** по 8 GB RAM каждый:

| Сервер | Назначение | RAM |
|---|---|---|
| Server 1 | API (FastAPI) + Nginx | 8 GB |
| Server 2 | Worker (Celery) | 8 GB |
| Server 3 | Worker (Celery) | 8 GB |
| Server 4 | PostgreSQL + Redis | 8 GB |
| Server 5 | Frontend (Next.js) | 8 GB |
| **ИТОГО** | | **40 GB RAM** |

Это **хорошая** база. Проблема в том, что видео-обработка (TTS + Merge) сейчас делается на Worker-серверах — это CPU-intensive задачи, которые съедают ресурсы.

## Как будет работать на 2000–3000 пользователей

### Архитектура

```
Пользователи (3000)
       ↓
  AWS Servers (API + Frontend) — лёгкая нагрузка
       ↓
  Modal (GPU compute — TTS + Merge)
       ↓
  Готовые видео → пользователю
```

### Разделение нагрузки

| Компонент | Где работает | Нагрузка при 3000 пользователях |
|---|---|---|
| **Frontend (сайт)** | AWS Server 5 | Статика, страницы — легко |
| **API (создание job'ов)** | AWS Server 1 | ~3000 HTTP-запросов в пик |
| **База данных** | AWS Server 4 | ~3000 INSERT/UPDATE в день |
| **TTS (озвучка)** | Modal (GPU) | ~3000 видео × 3 мин |
| **Merge (склейка видео)** | Modal (GPU) | ~3000 видео × 3 мин |
| **Redis (очередь)** | AWS Server 4 | Очередь задач |

## Стоимость при 3000 пользователях

### Предположения
- 3000 зарегистрированных пользователей
- 10% активны одновременно = **300 из них создают видео**
- Средняя длина видео: **3 минуты**
- В день: **~500 видео** (не все одновременно)

### AWS (уже есть)

| Сервер | Назначение | Стоимость/мес |
|---|---|---|
| **EC2** (×5 по 8GB) | API, Workers, DB, Redis, Frontend | ~$300 |
| **S3** | Хранение видео | ~$20 |
| **CloudFront** | CDN для видео | ~$30 |
| **ИТОГО AWS** | | **~$350/мес** |

**Примечание:** Серверы уже оплачиваются. При переносе видео-обработки на Modal, Worker-серверы (2 шт.) можно **уменьшить до t3.medium** или **выключить**, сэкономив ~$120/мес.

### Modal (GPU compute)

| Параметр | Значение |
|---|---|
| План | **Team** ($250/мес) |
| GPU concurrency | **50 GPU одновременно** |
| Containers | **5000** |
| GPU тип | T4 ($0.000164/sec) |

**Расчёт compute:**

```
500 видео/день × 3 мин × 60 сек = 90,000 сек compute/день
90,000 сек × $0.000164 = $14.76/день
$14.76 × 30 = $442.80/мес
```

**Но!** С 50 GPU concurrency:

```
50 GPU × 24 часа × 3600 сек = 4,320,000 сек/день доступно
90,000 сек нужно = 2% загрузка

Одно видео (3 мин) обрабатывается на 1 GPU за ~3 мин
50 видео параллельно = 50 GPU
500 видео/день = 10 waves × 3 мин = 30 мин total GPU time

Стоимость: 30 мин × 60 сек × $0.000164 × 50 GPU = $14.76/день
```

## Ограничения, о которых нужно знать

### 1. Modal GPU concurrency

| План | GPU concurrency | Макс. видео параллельно |
|---|---|---|
| Starter (бесплатно) | 10 | 10 |
| **Team ($250/мес)** | **50** | **50** |
| Enterprise | Custom | Custom |

**При 3000 пользователях нужен минимум Team план.** Starter (10 GPU) не хватит.

### 2. Cold start (холодный старт)

Когда Modal поднимает новый контейнер, это занимает **5–15 секунд**. После первого вызова контейнер "тёплый" и работает быстро.

**Решение:** Modal автоматически кеширует тёплые контейнеры. При пиковом наплыве первые 50 пользователей могут подождать 5–15 сек.

### 3. PostgreSQL при нагрузке

3000 пользователей = ~3000 INSERT/UPDATE в день. PostgreSQL на Server 4 (8GB RAM) выдержит **10,000+ запросов в секунду** — проблемы не будет.

### 4. Rate limits API

| Сервис | Лимит | Решение |
|---|---|---|
| Gemini (paid) | 1000 RPM | Купить больше |
| OpenAI Whisper | Нет жёсткого лимита | Плати = работай |
| Edge TTS | Нет лимита | Бесплатно, без ограничений |

## Ответ на частые вопросы

**Q: Не упадёт ли сайт при 3000 пользователях?**
A: Нет. 5 AWS серверов по 8GB = 40GB RAM. API и Frontend — лёгкая нагрузка. Тяжёлая работа (TTS, Merge) — на Modal.

**Q: Сколько стоит Modal при 3000 пользователях?**
A: ~$693/мес (Team план + compute). Для сравнения: 1 GPU сервер стоит ~$3000/мес.

**Q: Что если Modal упадёт?**
A: Modal имеет SLA 99.9%. В случае проблем — fallback на локальный worker (медленнее, но работает).

**Q: Нужно ли мне покупать GPU серверы?**
A: Нет. Modal = аренда GPU по секундам. Ничего не покупаете.

**Q: Как быстро масштабируется?**
A: Modal автоматически поднимает контейнеры за 5–15 секунд. При пиковом наплыве — 50 GPU параллельно = 50 видео одновременно.

**Q: Мои 5 серверов останутся?**
A: Да. Они будут обслуживать сайт, API и базу данных. Только видео-обработка перейдёт на Modal.
