# Обновление YouTube-куок на сервере — пошаговая инструкция

**Зачем:** сервис дубляжа использует куки как «вход» в YouTube. Когда они протухают, YouTube начинает блокировать скачивание видео. Наш мониторинг показывает: **сейчас куки на сервере протухли (~5,5 дней назад)** — пора обновить.

**Что нужно:** один раз в ~1-2 недели выполнить эти шаги. Занимает 5 минут.

---

## Способ 1 (проще, для не-программиста) — расширение браузера

### Шаг 1. Откройте YouTube в браузере без лишних расширений
Лучше в **режиме инкогнито** (Ctrl+Shift+N / Меню → Новое окно инкогнито).
- Зайдите на `https://www.youtube.com`
- **Убедитесь, что вы залогинены** (иконка аккаунта в правом верхнем углу).

> ⚠️ Используйте **тот же аккаунт**, под которым зарегистрирован сервис (если он был указан в настройках). Если входа нет — войдите.

### Шаг 2. Установите расширение «Get cookies.txt LOCALLY»
- В Chrome: [chrome.google.com/webstore](https://chromewebstore.google.com) → поиск **«Get cookies.txt LOCALLY»** → Установить.
- В Firefox: дополнения → «Get cookies.txt LOCALLY» → Добавить.

### Шаг 3. Скачайте куки
1. Кликните иконку расширения (пазл → иконка) на странице YouTube.
2. Нажмите **«Export» / «Скачать»**.
3. Сохранится файл **`cookies.txt`** (или `youtube.com_cookies.txt`).

### Шаг 4. Загрузите файл на сервер
```bash
# С телефона (Termux):
scp -i ~/.ssh/id_ed25519_whimco ./cookies.txt root@185.233.184.192:/opt/ai-dubber/cookies.txt
```
(Или вручную через любой SFTP-клиент: хост `185.233.184.192`, логин `root`, путь `/opt/ai-dubber/cookies.txt`.)

### Шаг 5. Перезапустите сервис куки (чтобы применилось)
```bash
# На сервере:
cd /opt/ai-dubber && systemctl restart ai-dubber-worker
```

### Шаг 6. Проверьте, что куки теперь свежие
```bash
# На сервере:
cd /opt/ai-dubber && ./venv/bin/python -c "import backend.services.cookie_manager as cm; print('дней до истечения:', round((cm.min_cookie_expiry()-__import__('time').time())/86400, 1))"
```
Должно быть положительное число (например `10.2`).

## Способ 2 (универсальный, из терминала) — yt-dlp

Если есть доступ к Chrome (на сервере или на телефоне с Chrome):
```bash
# 1. Убедиться, что Chrome залогинен в YouTube
# 2. Экспортировать куки:
yt-dlp --cookies-from-browser chrome \
       --cookies ./cookies.txt \
       --skip-download "https://www.youtube.com"

# 3. Скопировать на сервер
scp -i ~/.ssh/id_ed25519_whimco ./cookies.txt root@185.233.184.192:/opt/ai-dubber/cookies.txt

# 4. Перезапустить worker
ssh root@185.233.184.192 "systemctl restart ai-dubber-worker"
```

---

## Как часто обновлять

- Наш автоматический мониторинг (`min_cookie_expiry`) показывает, сколько дней осталось.
- Обновляйте, когда **дней осталось < 7** — проще раз в 1–2 недели.
- После обновления сервис сам подхватит куки (перезапуск воркера не обязателен, но ускоряет).

---

## Что если видео всё равно не качается?

1. Проверьте свежесть куок: `./venv/bin/python -c "import backend.services.cookie_manager as cm; print(cm.cookies_are_fresh())"`
2. Проверьте логи воркера: `journalctl -u ai-dubber-worker -f` — ищите `Sign in to confirm`, `cookies are no longer valid`.
3. Если есть — повторите шаги 1-6 выше с **свежем** экспортом.

*Если у вас нет того самого YouTube-аккаунта для сервиса — создайте его и залогиньте, тогда куки будут ещё стабильнее.*
